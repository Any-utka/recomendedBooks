# Book Recommender — рекомендательная система книг

Практический проект по машинному обучению. Автор: Доцен Анна, группа IASD02.

Пользователь выбирает книгу (или вводит новую, которой нет в каталоге) и получает 5 похожих книг из каталога с объяснением, почему они похожи. AI-агент отвечает на вопросы о книгах, а подборку можно отправить на email после проверки человеком.

**Цепочка системы:** данные → ML-модель → рекомендация → объяснение → AI-агент → действие (email, human-in-the-loop) → мониторинг.

---

## Запуск

Нужен установленный **Docker Desktop**.

1. Скопируйте `backend/.env.example` в `backend/.env` и впишите ключи (подробно — в самом файле). Обязателен только `GROQ_API_KEY`.
2. В корне проекта выполните:
   ```
   docker compose up --build
   ```
3. Откройте сайт: **http://localhost:8080**
   API (FastAPI): http://localhost:8000, документация: http://localhost:8000/docs

Остановка: `docker compose down`.

## Что умеет система

| Вкладка сайта | Что делает |
|---|---|
| **Рекомендации** | выбор книги из каталога → 5 похожих + объяснение от AI-агента + трендовая книга жанра; кнопка «Отправить подборку на email» |
| **По жанру** | выбор жанра и книги → похожие по жанру и рейтингу (Модель C) |
| **Новая книга** | поиск книги в Google Books или ручной ввод → 5 похожих из каталога с разбивкой сходства |
| **Дашборд** | живая аналитика по логу запросов + графики каталога |
| **Чат (кнопка справа внизу)** | AI-агент, который сам выбирает нужные инструменты |

## ML-модели

| Модель | Признаки | Назначение |
|---|---|---|
| A | TF-IDF описания | сходство по смыслу текста |
| B | one-hot жанра + нормализованные страницы | сходство по жанру и объёму |
| **Гибрид (финальная)** | `0.7 × A + 0.3 × B` | основные рекомендации; веса выбраны по метрикам силы сходства и разнообразия |
| C | жанр + рейтинг | вкладка «По жанру» |
| Linear Regression, Random Forest | жанр, страницы, наличие описания | эксперимент: можно ли предсказать рейтинг книги (R² < 0 — нельзя) |

**Предсказание на новых данных:** описание, жанр и страницы новой книги переводятся в те же признаки (`tfidf.transform`, тот же one-hot, тот же `MinMaxScaler`) без переобучения модели.

**Объяснимость:**
- для рекомендаций — точная разбивка сходства `0.7 × текст + 0.3 × жанр/страницы` (показывается на сайте);
- для Random Forest — feature importance и **SHAP** (общая картина и разбор прогноза одной книги, ноутбук, раздел 5.4–5.5).

## AI-агент

LLM: `openai/gpt-oss-20b` через Groq API. Агент сам решает, какие инструменты вызвать:

1. `search_book` — поиск книги в каталоге
2. `get_recommendations` — ML-рекомендации (гибридная модель)
3. `get_trending_in_genre` — популярные книги жанра
4. `compare_books` — сравнение двух книг
5. `find_books_by_genre` — книги по жанру
6. `search_google_books` — поиск во внешнем API Google Books
7. `recommend_for_external_book` — похожие книги из каталога для книги, которой в каталоге нет

Агент анализирует результат (предупреждает о слабом сходстве < 0.2) и в конце предлагает пользователю следующее действие. Рекомендует только книги из каталога — то, что есть в наличии.

## Автоматизация (RPA) с участием человека

Кнопка «Отправить подборку на email»:
1. агент готовит черновик письма (рекомендации модели + совет LLM, с какой книги начать);
2. человек проверяет и при необходимости редактирует текст;
3. письмо отправляется через Gmail SMTP **только после нажатия «Отправить»**.

---

## Мониторинг

Каждый запрос записывается в `backend/logs/requests.jsonl`. Вкладка «Дашборд» показывает:
- спрос: число подборок по дням, самые запрашиваемые книги и жанры;
- **«Ищут, но нет в каталоге»** — кандидаты на закупку;
- качество модели: среднее сходство, доля слабых рекомендаций (< 0.2), доля того же жанра, coverage каталога.

## Ограничения

- ≈25% книг без описания — для них работает только сходство по жанру и объёму;
- каталог на 95.6% англоязычный — модель работает с английскими описаниями;
- нет данных о пользователях (истории чтения), поэтому система content-based и нет точной метрики качества рекомендаций;
- рейтинг книги не предсказывается по её метаданным (R² < 0, подтверждено SHAP).
